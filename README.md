# agenticfeeder.com feedback

Reports about [agenticfeeder.com](https://agenticfeeder.com), a daily news site on AI and agentic AI
with labelled AI-written digests.

Open an issue to:

- **report an error** in an AI-written entry, a summary or a link;
- **ask for removal** of a source you publish (the source is dropped from the next daily build);
- **report a security problem** with the site.

Please give the page address and what is wrong. How the site is made: <https://agenticfeeder.com/about/>.
